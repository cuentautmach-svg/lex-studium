# Materiales compartidos de Lex Studium

Esta carpeta contiene archivos públicos (PDF, Word, PowerPoint, Excel, imágenes, ZIP y otros formatos) publicados por la administración de Lex Studium.

## Cómo subir documentos
1. Inicia sesión en GitHub con la cuenta propietaria del repositorio.
2. Abre esta carpeta y usa **Add file → Upload files**.
3. Selecciona los archivos y pulsa **Commit changes**.
4. En Lex Studium abre **Biblioteca → Archivos compartidos → Actualizar**.

También puedes organizar los documentos en subcarpetas, por ejemplo `materiales/Derecho Civil I/`.

## Importante
- Los archivos añadidos aquí son **públicos** y pueden descargarse.
- No publiques documentos privados, datos personales de estudiantes ni materiales sin permiso de distribución.
- El repositorio usa GitHub Pages y el catálogo consulta la lista pública de GitHub.
